Руководство пользователя

1. Назначение

Приложение предназначено для просмотра TIFF-стеков и их масок, наложения сетки на кадры и генерации массива заполненности ячеек по маске.

Программа поддерживает:
- одиночную обработку выбранной пары файлов
- групповую обработку набора файлов в выбранной папке


2. Запуск

Запустите приложение командой:

python tiff_grid_viewer.py


3. Загрузка файлов

В верхней части окна находятся два поля:
- TIFF — путь к основному TIFF-стеку
- Mask TIFF — путь к TIFF-стеку маски

Можно:
- ввести путь вручную
- нажать кнопку "Обзор..." и выбрать файл через диалог

После выбора файлов нажмите кнопку "Загрузить".


4. Просмотр кадров

После загрузки пары файлов:
- слева отображается исходный TIFF
- по центру отображается mask TIFF
- справа отображается визуализация заполненности ячеек после генерации массива

Для навигации по кадрам используйте:
- горизонтальный слайдер
- кнопки "<<" и ">>"
- стрелки клавиатуры влево и вправо

Все три панели синхронизированы по номеру кадра.


5. Построение сетки

Поле "Размер ячейки (px)" задаёт размер ячейки сетки в пикселях.

Варианты задания:
- выбрать одно из предложенных значений в выпадающем списке
- ввести размер вручную

После этого нажмите "Построить сетку".

Сетка отображается поверх изображений.
Если размер не делит изображение без остатка, крайние ячейки будут неполными.

Кнопка "Скрыть сетку" убирает отображение сетки.


6. Формирование массива

Поле "Число нулей N" задаёт, сколько нулей должно идти после основного значения заполненности.
Для новых NCA-экспериментов рекомендуемое значение — 0: скрытые каналы должна добавлять модель, а не файл данных.

Для каждой ячейки формируется вектор:

[fill_ratio, 0, 0, ..., 0]

где:
- fill_ratio — доля ненулевых пикселей в ячейке маски
- число нулей после него равно N; при N = 0 вектор равен [fill_ratio]

Итоговый массив имеет форму:

[T, H, W, N + 1]

где:
- T — число кадров
- H — число строк сетки
- W — число столбцов сетки
- N + 1 — длина вектора каждой ячейки

Чтобы создать массив:
1. загрузите TIFF и mask TIFF
2. задайте размер ячейки
3. нажмите "Построить сетку"
4. задайте число нулей N
5. нажмите "Сгенерировать массив"

После этого:
- массив вычисляется по маске
- файл `.npy` сохраняется на диск
- справа появляется цветовая визуализация заполненности ячеек


7. Куда сохраняется `.npy`

При одиночной обработке файл сохраняется рядом с mask TIFF.

Имя файла формируется по шаблону:

<имя_mask>_grid_<размер_ячейки>_zeros_<N>.npy

Пример:

sample_mask_grid_32_zeros_0.npy


8. Цветовая визуализация

Правая панель показывает заполненность ячеек цветом.

Особенности:
- чем выше заполненность, тем интенсивнее цвет
- до генерации массива правая панель остаётся пустой
- после генерации массив можно просматривать покадрово так же, как исходные TIFF


9. Групповая обработка

Кнопка "Обработать группу" запускает пакетную обработку.

Порядок работы:
1. нажмите "Обработать группу"
2. выберите корневую папку
3. программа рекурсивно обойдёт все подпапки
4. будут найдены пары файлов:
   - основной TIFF
   - соответствующий `_mask.tif`, `_mask.tiff` или `LblImg_*.tif`
5. пользователю будет показан список найденных пар и их количество

Поиск учитывает:
- `.tif`
- `.tiff`
- расположение файлов в разных подпапках

Пары определяются по совпадению базового имени файла:
- `sample.tif` и `sample_mask.tif`
- `sample.tiff` и `sample_mask.tiff`
- `sample.tif` и `LblImg_sample.tif`
- также допустимы смешанные расширения `.tif` и `.tiff`


10. Режим сохранения при групповой обработке

В диалоге пакетной обработки есть переключатель:

"Сохранить здесь: в текущей директории, в папке processed_arrays"

Если переключатель включён:
- все результаты сохраняются в папку `processed_arrays`
- структура подпапок сохраняется относительно выбранной корневой папки

Если переключатель выключен:
- каждый `.npy` сохраняется рядом со своим mask TIFF


10.1. Воспроизводимая CLI-обработка для NCA

Для обучения NCA предпочтительно использовать скрипт `build_nca_maps.py`, потому что он:
- сохраняет массивы со split-структурой
- пишет `manifest.jsonl`, `qc.csv` и `summary.json`
- умеет делать `[T, H, W, 1]` без лишних нулевых каналов
- умеет добавлять occupancy и TrackMate-каналы
- поддерживает split по группам, например по `pos`

Пример для DynamicNuclearNet:

python3 build_nca_maps.py \
  --source-root "../DynamicNuclearNet/DynamicNuclearNet/tif_data" \
  --out-root "../../../NCA/data_v2" \
  --dataset dnn \
  --grid-size 8 \
  --channels density \
  --split-policy by_group \
  --split-ratios 0.6 0.2 0.2 \
  --overwrite


11. Завершение обработки

После успешной групповой обработки программа показывает сообщение, что всё обработалось успешно.

Если для части пар возникнут ошибки, программа сообщит об этом отдельно.


12. Возможные причины ошибок

Обработка может не выполниться, если:
- не выбраны TIFF и mask TIFF
- размер ячейки не задан или некорректен
- число нулей N меньше 1
- размеры кадров TIFF и mask TIFF не совпадают
- количество кадров TIFF и mask TIFF не совпадает
- файл повреждён или не читается


13. Рекомендуемый порядок работы

Для одиночного файла:
1. загрузить TIFF и mask TIFF
2. выбрать размер ячейки
3. построить сетку
4. указать число нулей N
5. сгенерировать массив
6. проверить визуализацию справа

Для группы файлов:
1. выставить нужный размер ячейки
2. указать число нулей N
3. нажать "Обработать группу"
4. выбрать папку
5. проверить список найденных пар
6. выбрать способ сохранения
7. запустить обработку
